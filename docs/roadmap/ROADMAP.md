# Roadmap

Tracked in the `redmine-todo` project on the home tracker; the feature description is ticket #1612.

## Planned

1. Each item is a ticket; the item text is the ticket subject.
2. The checkbox closes the ticket and crosses the item out.
3. Dragging an item onto another nests it (parent and child), like bullet lists in Apple Notes.
4. Editing an item in place updates the ticket subject.
5. Hovering an item shows a card with the ticket details.
6. A modal opens the full ticket edit (more fields, file uploads).
7. Right-clicking an item opens a quick-action context menu.

## Open

- Which quick actions go in the context menu.
- The license (Redmine itself is GPL v2).
