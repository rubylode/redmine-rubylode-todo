# Roadmap

## Done

1. Each item is a ticket; the item text is the ticket subject.
2. The checkbox closes the ticket and crosses the item out.
3. Dragging an item onto another nests it (parent and child), like bullet lists in Apple Notes.
4. Editing an item in place updates the ticket subject.
5. Hovering an item shows Redmine's ticket tooltip.
6. A dialog opens the full ticket edit (more fields, file uploads).
7. Right-clicking an item opens Redmine's context menu.
8. Settings for the defaults of new lines (1.1.0).
